# AuraOS
An integrated software solution for motor-disabled patients that provides hands-free device control alongside real-time vital sign surveillance.

* Motor-impaired individuals face significant physical barriers when using standard     computer.
* Existing eye-tracking hardware is often expensive and inaccessible for everyday users.
* AuraOS provides a low-cost, hands-free computer utilizing solution using just a standard webcam.

* My project can use computer without using hands but just with eyes using webcam , it can click , scroll and type . i have to make better ui and working design and have to solve few glitches it is facing . It works with (60-70)% accuracy for now , i should make it more accurate.I have built a functional computer vision pipeline integrating the MediaPipe Face Landmarker, OpenCV, and scikit-learn regression models. The system processes real-time webcam feeds to accurately track iris positions and calculates the Eye Aspect Ratio (EAR) to monitor blinking patterns.
